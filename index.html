    使用说明

    1. 建档：在「资产台账」新增资产，或用「导入 CSV」批量导入；资产编号是唯一标识，建议用字母数字组合。导入的表头可用：资产编号、资产名称、分类、存放位置、保管人、状态、备注（UTF-8 编码）。新增/编辑时可上传资产照片，系统自动压缩到约 40KB 再上传，用于留档核对。
    2. 贴码：在「标签打印」选模板与范围，预览确认后用标准打印或直连标签机打印，把标签贴到资产上。模板可改尺寸、字段、排版并另存；台账里勾选资产后点「打印标签」会直接跳转过来。
    3. 盘点：在「扫码盘点」选择范围后开始，开启摄像头逐件扫码；无摄像头时用手动输入框录入编号。
    4. 结果：实时显示已盘 / 未盘，结束后自动生成记录，可导出 CSV 作为盘亏清单。

    台账与盘点记录保存在本机浏览器（不上传）；资产照片会压缩到约 40KB 后上传到服务器，换电脑登录也能看到。换设备或清理浏览器数据前，请用顶部「备份数据」导出 JSON 文件；恢复时点「恢复数据」。

    摄像头需要 HTTPS 或 localhost 环境。若双击打开本文件无法扫码，请在本目录运行 python3 -m http.server 8000，然后访问 http://localhost:8000。
